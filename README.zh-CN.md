### 🧑‍💻 关于我

- 喜欢做**小而精的工具**：菜单栏应用、启动器、脚本——装上之后就不用再操心的那种。
- 主要在做 **macOS 桌面小工具**（Swift / SwiftUI）和 **AI Agent 工作流**（Claude Code、Codex）。
- 做的东西尽量**本地优先**，不收集你的数据。
